    Class ImageExtractor

    Image extraction from PDF files using pdf-lib (clean implementation based on NestJS)

    Supports multiple extraction engines including pdf-lib and poppler for maximum compatibility and performance. Can extract image metadata, save image files, and handle various image formats.

    Example 

    const imageExtractor = new ImageExtractor();
    const result = await imageExtractor.extract('document.pdf', {
      extractImageFiles: true,
      imageOutputDir: './images',
      imageEngine: 'auto'
    });
